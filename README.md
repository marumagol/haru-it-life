# 하루살이 IT 인생: 신입부터 정년까지

IT 회사 생존 시뮬레이션 웹 게임의 첫 플레이 가능한 프로토타입(v0.1)입니다. 도트 그래픽 없이 단순한 화면으로 한 판을 끝까지 플레이할 수 있어요.

## 플레이 방법
- 공개 주소(GitHub Pages)로 접속하면 바로 플레이할 수 있어요.
- 진행은 브라우저에 자동 저장돼요(저장 슬롯 1개, 되돌리기 없음).

## 들어간 것
- 캐릭터 만들기: 이름 · 직군 4종 · 시작 배경 4종 · 성격 문답 6개(숨은 성향 4종)
- 취업 준비로 시작: 반기마다 구직 카드 → 합격하면 첫 회사 선택 (대기업은 스펙이 좋아야 드물게)
- 1턴 = 1년: 상반기·하반기 행동 카드(3장 중 1장 또는 "평소처럼") → 이벤트 → 상점 → 연말 보고서
- 역량 6개(실무력·소통력·트렌드 감각·리더십·정치력·멘탈) 육각형, 체력·스트레스 게이지, 돈·사내 입지·업계 평판
- 고과(S~D), 연봉·생활비, 승진(관리자/실무자 트랙 분기), 상사 7유형, 동기 2명 비교, 회사 상태(호황~위기)
- 이벤트 약 50개(일상·직군·회사·상사·동기), 시대 이벤트 5개, 위기(번아웃·고립·월급 밀림·부도·권고사직·명예퇴직)
- 헤드헌터 이직·카운터오퍼, 구직 턴, 수상, 엔딩 22종, 60세 정년(2045년 이후 연장 근무)

## 아직 안 들어간 것 (2차)
도트 그래픽, 전직 시스템, 스톡옵션·스타트업 단계 성장, 창업·프리랜서 루트, 대출·투자, 커리어 앨범·도감, 공유 카드, 효과음

## 수치 조정하기
- 모든 수치는 `data/balance.json`, 이벤트는 `data/events.json`, 엔딩 문구는 `data/endings.json`에 있어요.
- 게임 첫 화면의 **개발자 설정**에서 숫자를 바꾸고 [적용]하면 그 브라우저에서만 바로 반영돼요. 마음에 들면 같은 내용을 `data/balance.json`에 붙여넣어 저장하면 모두에게 반영돼요.
- 개발자 설정의 **자동 플레이 시뮬레이터**로 여러 판을 돌려 정년 도달률, 고과 분포, 40세 직급, 엔딩 분포를 확인할 수 있어요.
- 한 판 길이는 `시작.정년`(기본 60), `시작.나이`(기본 24), `이벤트확률`로 조절해요.

## 임시로 정한 값 (규칙서에 공식이 비어 있던 부분)
- 대체 가능성: `기본 25 − 실무력×0.3 − 트렌드×0.2(2028년 이후 0.4) + 보정`
- 선택지 판정: `50 + (내 능력치 − 요구치)`, 5~95% 제한
- 헤드헌터 기본 확률 15%, 행복도 기본값 40 등은 `balance.json`의 `_메모`를 참고하세요.

## 개발자용
```
node tools/sim.mjs 300 무작위   # 터미널에서 시뮬레이터 실행 (전략: 무작위 | 균형 | 야근만)
python3 -m http.server          # 로컬에서 열기 → http://localhost:8000
```
빌드 과정 없이 HTML·CSS·JavaScript 파일만으로 동작해요.
